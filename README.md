# Personal Portfolio Web App

## Overview

This project is a Personal Portfolio Web App created using Node.js, Express, and EJS. The purpose of this software is to showcase my programming projects, skills, and contact information in a professional portfolio website.

The web app dynamically generates pages using Express routes and EJS templates instead of only using static HTML pages.

This project includes:
- Home page
- Projects page
- Contact page
- Interactive contact form
- Dynamic project cards
- Responsive design

[Software Demo Video](https://youtu.be/2V4jIEhF4J8)

---

# Web Pages

## Home Page
The Home page introduces who I am, my background as a Software Engineering student, my skills, and navigation links to other pages.

## Projects Page
The Projects page dynamically displays portfolio projects using data stored in a JavaScript array. Each project contains an image, description, technologies used, and project link.

## Contact Page
The Contact page contains clickable contact links and an interactive contact form that validates user input and displays a confirmation message.
